# LR2 SS Mover

LR2 SS Mover is a lightweight automation tool designed to intelligently organize and manage your screenshots from LR2 (Lunatic Rave 2) or LR2HD.

## 🌟 Key Features

- **Auto-Sorting by Date**: Instantly moves new screenshots into automatically created date-based folders, keeping your directories clutter-free.
- **Smart Auto-Start**: Automatically begins monitoring as soon as the application is launched—no manual intervention required.
- **Windows Startup Integration**: Easily register the tool to run when Windows starts via the settings menu.
- **Silent Startup**: When launched via Windows Startup, the tool starts minimized in the system tray to stay out of your way during gameplay.

## 🚀 How to Use

1. **Source Path**: Select the folder where your screenshots are saved (e.g., your LR2 `Snapshot` folder).
2. **Destination Path**: Select the base directory where you want the sorted date-folders to be created.
3. **Run**: Keep the tool running; it handles all the heavy lifting in the background.

## 📋 Requirements
- Windows 10 / 11
- Python 3.10.x
- [watchdog](https://pypi.org/project/watchdog/) (Library for file monitoring)

# LR2 SS Mover

LR2 SS Mover は、LR2 (Lunatic Rave 2) や LR2HD のスクリーンショットを自動で整理・管理するための軽量なオートメーションツールです。

## 🌟 主な機能

- **日付別オートフォルダ仕分け**: スクリーンショットが保存された瞬間、設定した日付フォルダへ自動的に移動します。デスクトップやフォルダが散らかるのを防ぎます。
- **スマート・オートスタート**: ツールを起動した瞬間に監視を自動開始。毎回ボタンを押す手間を省きます。
- **Windows スタートアップ対応**: 設定画面からワンクリックで Windows 起動時の自動実行を登録できます。
- **サイレント起動**: スタートアップ起動時は最小化状態で立ち上がるため、プレイの邪魔になりません。

## 🚀 使い方

1. **監視元**: LR2HDなどのスクショが保存されるディレクトリを選択してください。
2. **移動先**: 整理後のフォルダが作成される場所を選択してください。
3. あとはツールを起動しておくだけで、自動で整理が開始されます。

## 📋 動作環境
- Windows 10 / 11
- Python 3.10.x
- [watchdog](https://pypi.org/project/watchdog/) (ファイル監視ライブラリ)
